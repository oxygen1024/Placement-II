# 長者節日 AR 影相框

俾長者中心小組活動用嘅網頁影相遊戲：長者望住電視（或者 MacBook 螢幕），系統會自動幫佢哋「戴」上節日頭飾，再加上節日相框，由工作員撳掣影相同儲存。

- 單一檔案：`index.html`（HTML + CSS + JavaScript 全部喺入面）
- 用 **Google Chrome** 開啟
- 所有裝飾都係用程式即場畫出嚟，冇用任何外部圖片或者卡通人物
- **所有鏡頭影像只喺部電腦入面處理，唔會上載**

---

## 一、點樣開啟（揀一個方法）

> 第一次開需要**連接互聯網**（要下載臉部偵測程式庫同模型，約 10MB）。之後 Chrome 一般會記住，但活動前最好都確認有網絡。

### 方法 A：雙擊 `start-mac.command`（最簡單）

1. 喺 Finder 雙擊 `start-mac.command`
2. 會彈出一個「終端機」視窗，然後 Chrome 會自動打開 `http://localhost:8000`
3. **用完先關閉個終端機視窗**（中途唔好關）

如果 Mac 話「無法打開，因為來自未識別的開發者」：對住個檔案 **撳右鍵 → 打開 → 再撳「打開」**（只需要做一次）。
如果話冇權限執行：開「終端機」輸入 `chmod +x `（後面有空格），將檔案拖入視窗，按 Enter。

### 方法 B：用終端機（技術人員／工作員）

```bash
cd 呢個資料夾的位置        # 例如：cd ~/Desktop/ar-photo-frame
python3 -m http.server 8000 --bind 127.0.0.1
```

然後用 Chrome 開：**http://localhost:8000**

- `--bind 127.0.0.1` 代表只有呢部電腦自己可以連入，同一個 Wi-Fi 嘅其他人連唔到。
- 如果部 Mac 第一次打 `python3`，可能會叫你安裝「指令列開發者工具」，跟指示安裝就得。
- 如果話 8000 已經有人用緊，將兩個 `8000` 改做 `8080` 等其他數字。

### 方法 C：直接雙擊 `index.html`（後備）

Chrome 一般都可以直接開，但每次開都會問一次鏡頭權限。如果出現「網頁開啟方式唔啱」嘅提示，請改用方法 A 或 B。

## 二、活動當日點用

1. 開咗網頁之後，撳 **「開始 ▶」**（或者按空白鍵）
2. Chrome 問「使用相機」→ 撳 **「允許」**
3. 撳右上 **「⚙ 設定」**，輸入 **活動名稱**（會印喺相片底部），日期會自動填今日
4. 接駁電視／投影機後按 **F** 開全螢幕；再按 **C** 可以收埋所有按鈕，畫面更大
5. 用 **← →** 揀主題，按 **H** 轉頭飾（包括「唔戴」）
6. 長者準備好，按 **空白鍵** → 全螢幕大字倒數 **3、2、1**，同時用廣東話讀出「三、二、一，笑一笑！」→ 閃光 → 出預覽
7. 工作員決定：
   - **S**／「💾 儲存相片」→ 相片（PNG）存入 Mac 嘅「下載項目」資料夾
   - **空白鍵**／「🔄 再影過」→ 唔儲存，返去再影
   - 相片**唔會自動儲存**，一定要工作員撳先會存

### 笑一笑自動影相

按 **A**（或者撳「😊 笑一笑自動影相」）開啟。系統見到有人笑（嘴角向上）並維持大約 1 秒，就會自動開始倒數。畫面底部有一條進度棒，長者可以見到「笑容」儲緊。
如果長者笑容比較含蓄，可以喺「設定」揀「少少笑都得」。

## 五、小貼士

- **距離**：MacBook 鏡頭大約要**坐喺 1 米之內**先偵測到塊面。太遠會見到「🙂 請行近少少」。
- **燈光**：面前要夠光，唔好背住窗。太暗會見到「💡 開多盞燈」。
- **多人合照**：最多同時偵測 6 個人，每人都會有頭飾。
- 滑鼠 3 秒唔郁會自動收埋，接電視時唔會見到箭咀。
- 如果部 Mac 接咗 iPhone（接續互通相機），系統會優先用 MacBook 內置鏡頭；要轉鏡頭可以喺「設定」揀。

## 六、私隱

- 鏡頭畫面、臉部偵測全部喺 Chrome 入面、喺呢部電腦處理，**唔會上載任何影像或資料**。
- 網頁只會喺開啟時由網上**下載**：MediaPipe 程式庫（jsDelivr）同臉部偵測模型（Google）。
- 倒數讀聲會優先用 Mac 內置嘅廣東話聲音。
- 相片只會喺工作員撳「儲存」後存入「下載項目」資料夾。
- 建議：影相前先得到長者同意；活動後按機構私隱政策處理相片（例如派相後刪除電腦上嘅檔案）。

## 七、常見問題

**Q：撳「開始」後話「未有權限」？**
撳 Chrome 網址列右邊嘅鏡頭圖示（或者網址左邊嘅網站設定圖示），將「相機」改為「允許」。如果仍然唔得：Mac「系統設定」→「私隱與安全性」→「相機」→ 開啟「Google Chrome」，然後重新開 Chrome。

**Q：話「鏡頭俾其他程式用緊」？**
關閉 Zoom、Teams、FaceTime、Photo Booth，同埋其他用緊鏡頭嘅 Chrome 分頁，再撳「再試一次」。

**Q：話「臉部偵測功能載入失敗」？**
通常係冇網絡。接好 Wi-Fi 再撳「再試一次」。急用可以撳「只用相框繼續」：冇頭飾，但一樣可以影相同儲存。

**Q：倒數冇聲，或者讀咗普通話／英文？**
- 檢查「設定」→「倒數讀出聲」係咪「開」，同埋 Mac 音量。
- Mac「系統設定」→「輔助使用」→「朗讀內容」→「系統聲音」→「管理聲音…」，加入「中文（香港）」嘅聲音（例如 Sinji），然後重新開 Chrome。

**Q：頭飾有少少跟唔上／震？**
行近少少、開多盞燈會準確好多。系統已經加咗平滑處理，頭郁得快時會稍為遲少少先跟上，係正常。

## 八、技術資料（俾技術人員）

- 臉部偵測：`@mediapipe/tasks-vision@0.10.21` Face Landmarker（由 jsDelivr 載入），`runningMode: VIDEO`，`numFaces: 6`，`outputFaceBlendshapes: true`；GPU 失敗會自動改用 CPU
- 模型：`https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task`
- 定位：額頂 landmark **10** 放頭飾；兩邊臉頰 **234、454** 計臉寬（連 z 軸，轉頭時大小較穩定）決定大小；兩眼外角 **33、263** 計頭部傾側角度並旋轉頭飾
- 平滑：自適應指數平滑（郁得少跟得慢防抖，郁得多跟得快唔拖尾），角度平滑有處理 ±180° 交界；頭飾淡入淡出
- 笑容：`mouthSmileLeft`、`mouthSmileRight` 平均值超過門檻（0.30／0.45／0.60）並維持約 1 秒
- 光線：每 0.5 秒將鏡頭畫面縮細計平均亮度
- 相片解像度：至少 1080 像素高（例如 1920×1080），PNG
- 設定（活動名稱、頭飾選擇等）只存喺 Chrome 嘅 localStorage；日期每次開都會用當日
- 除錯：喺 Chrome「開發人員工具」Console 輸入 `arPhotoFrame.faces` 可以睇到偵測結果
